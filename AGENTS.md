# Working on engineering standards

Start with the [contributor guide](CONTRIBUTING.md). It defines the issue and milestone branches, verification evidence, handoffs, owner checkpoints, and merge authority for this repository.

Use the [roadmap](docs/plans/2026-11-17-roadmap.md) to locate the active milestone. Read its spec, the plan section linked by your issue, and the current issue and PR discussion before editing. The [Standards board](https://github.com/users/edward-sf/projects/11) records claims and status.

For an existing branch, follow the [handoff procedure](CONTRIBUTING.md#hand-off-an-open-issue). For new work, [claim a ready issue](CONTRIBUTING.md#plan-and-claim-work). The owner reviews and merges milestone PRs into main.
